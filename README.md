# 🏛️️ AOU Clubs Portal

A responsive web application designed for university students to explore campus clubs, track upcoming campus events, and stay updated with official student organization announcements.

---

## 🚀 Key Features

* **Club Directory:** Browse student clubs categorized by academic and cultural interests.
* **Events & Announcements Board:** Dedicated sections to showcase upcoming campus activities, registration links, and news.
* **Responsive Layout:** Optimized with modern CSS Flexbox and Grid to provide a seamless browsing experience across mobile, tablet, and desktop devices.
* **Dynamic Interactions:** Client-side DOM manipulation powered by JavaScript for fluid user interactions.

---

## 🛠️ Built With

* **Markup:** Semantic HTML5
* **Styling:** CSS3 (Flexbox, CSS Grid, Custom Media Queries)
* **Scripting:** JavaScript (Vanilla JS / DOM Manipulation)
* **Editor:** VS Code
